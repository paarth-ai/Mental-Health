Getting Started

1

Clone Repository

git clone https://github.com/paarth-ai/Mental-Health.git
2

Create Virtual Environment

python -m venv .venv
3

Install Dependencies

pip install -r requirements.txt
4

Run Migrations

python manage.py migrate
5

Start Server

python manage.py runserver
6

Visit Application

http://127.0.0.1:8000/
